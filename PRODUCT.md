# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Inferred from the supplied assignment and confirmed by the user's instruction to start building: React with Vite, Tailwind CSS, GSAP ScrollTrigger, and GitHub Pages deployment. React is the selected interpretation of the assignment's “Next.js/React.js” requirement.

## Users

The primary audience is Itzfizz Digital's hiring team reviewing a web-development internship assignment. They need to quickly assess frontend animation skill, interaction logic, code quality, responsiveness, and deployment readiness.

## Product Purpose

Deliver a polished, scroll-driven hero experience inspired by the supplied car animation reference. Success means a live public webpage and readable GitHub repository that demonstrate smooth load animation, scroll-linked motion, responsive behavior, and careful frontend implementation.

## Positioning

The submission distinguishes itself through one tightly directed interaction: scrolling physically drives the hero's focal vehicle, reveals the Itzfizz welcome message, and stages impact metrics as a single coherent motion system.

## Operating Context

The evaluator will open a hosted link, interact by scrolling on desktop or mobile, and inspect the source repository. The submission deadline is 27 October 2026.

## Capabilities and Constraints

- The first screen is a full-height hero.
- The headline reads “WELCOME ITZFIZZ” with deliberate letter spacing.
- Four percentage-based demonstration metrics appear with short descriptions.
- Load animation reveals the headline and metrics in a staggered sequence.
- Scroll progress, not autoplay time, drives the main visual.
- Motion prioritizes transforms and avoids scroll-time React re-renders or layout thrashing.
- The site must be responsive and include reduced-motion behavior.
- Required technologies are HTML, CSS, JavaScript, React, Tailwind CSS, and GSAP.
- Delivery requires a live webpage link and GitHub repository link.

## Brand Commitments

The Itzfizz name and the supplied reference interaction are binding. No official logo, typeface, palette, or proprietary brand assets were supplied, so this project creates a distinct assignment-only visual interpretation without claiming it is Itzfizz's official identity.

## Evidence on Hand

The supplied assignment brief and reference demo are the only evidence. The percentage metrics are illustrative content inherited from the reference and must not be presented as verified company performance claims.

## Product Principles

- Make the interaction understandable within one scroll gesture.
- Let motion demonstrate technical competence rather than decorate the page.
- Keep the implementation inspectable, modular, and performant.
- Treat desktop and mobile as intentional compositions.
- Do not fabricate business claims or official branding.

## Accessibility & Inclusion

Use semantic markup, visible focus treatment, readable contrast, meaningful alternative text, and a `prefers-reduced-motion` experience that retains all information without prolonged pinning.
